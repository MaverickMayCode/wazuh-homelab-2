This project will cover the following areas:
- Splunk - hosted on an Ubuntu Server VM
- Active Directory - hosted on a Windows Server 2022 VM
- Windows Systems - Windows 10 VM

1. First, we started by creating a diagram of our project including: a router, a switch, a computer (Windows 10), another computer (Kali Attacker), a server (Splunk), another server (Windows Server 2022), and, of course, the internet.
2. Second, we installed our VMs including: Windows 10, Kali Linux, Ubuntu Server, and Windows Server 2022.
  1. For Windows 10 we went to microsoft.com and navigated to the Windows 10 Media Creation Tool for download.
  2. For Kali we went to kali.org -> virtual machines -> Hyper V Windows 10.
  3. For Windows Server 2022 we downloaded the ISO, setup in VM, and used the Desktop Experience version for install.
  4. Lastly for our Splunk server we went to the ubuntu site -> products -> ubuntu server -> manual install -> and installed ubuntu 26.04.1 LTS.
